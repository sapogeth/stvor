================================================================================
SECURITY GUARANTEES
================================================================================

Network Layer (EREBUS Mitigation):
  ✅ Proves relay authenticity (Ed25519 signatures)
  ✅ Challenge-response with nonce-based protocol
  ✅ Backup relay failover
  ✅ Verification caching (60s TTL)
  ❌ Does NOT prevent relay operator compromise
  ❌ Does NOT hide connection from ISP

Transport Layer (Traffic Analysis Resistance):
  ✅ Hides message length (padded to block size)
  ✅ Constant block sizes (256/512/1024 bytes)
  ✅ Random padding bytes
  ✅ Configurable jitter (±percentage)
  ❌ Does NOT hide message frequency
  ❌ Increases bandwidth 10-30%

Application Layer (Side-Channel Mitigation):
  ✅ Typing indicators disabled by default
  ✅ Read receipts disabled by default
  ✅ Strict opt-in model
  ✅ Event batching (5 per 2 sec max)
  ✅ Random timing delays (1-5 sec)
  ❌ Still visible to relay server
  ❌ Increases perceived latency
