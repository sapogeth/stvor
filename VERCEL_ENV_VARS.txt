STEP-BY-STEP SETUP INSTRUCTIONS
================================================================================

1. Open: https://vercel.com/dashboard

2. Select your web app project (stvor-web or similar)

3. Click: Settings (top navigation)

4. Click: Environment Variables (left sidebar)

5. For each variable above:
   a. Click: + Add New
   b. Enter Variable Name (e.g., RELAY_BASE_URL)
   c. Enter Value (e.g., https://ilyazhrelay-production.up.railway.app)
   d. Select Scope: Production
   e. Click: Save

6. After adding RELAY_BASE_URL and NEXT_PUBLIC_RELAY_URL:
   a. Vercel will automatically redeploy
   b. OR click: "Deployments" → "Deploy" to force redeploy
   c. Wait 2-3 minutes for deployment to complete

7. Test the application:
   a. Go to: https://stvor-web.vercel.app/groups
   b. Create a group
   c. Accept an invitation
   d. Send a message in group
   e. Verify no 502 errors
